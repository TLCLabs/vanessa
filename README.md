# TLC Labs - Vanessa

The aim of this project is to create an Open Source Vacuum Cleaner through our vision:

*"To fundamentally improve the lives of people by creating reliable, open-source appliances that eliminate e-waste, while proving that a compassionate, employee-first business model can successfully compete in the modern market."* - TLC Labs

Vanessa will be a mid-to high-range appliance built from a combination of 3D-printed parts, standard hardware, and readily available electronics. Like all TLC Labs projects, it will be 100% open source and free to reproduce under the `CERN Open Hardware Licence Version 2 - Strongly Reciprocal`. We aim to make Vanessa as easy to build at home as possible.

## Design

* Corded Stick Vacuum
* Cyclonic Dust Separator
* Analog - No Motor Drivers
