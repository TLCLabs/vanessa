## Refreshing the snapshots

1. Choose and review a revision of `TLCLabs/EmployeeHandbook` in a separate
   checkout. Ensure these three files have no uncommitted changes.
2. Copy `manifesto.md`, `guiding-principles-of-leadership.md`, and `LICENSE.md`
   from that revision into this folder without modifying their contents.
3. Update the source revision and link above using `git rev-parse HEAD` from
   the handbook checkout. Preserve attribution and review any license changes.
4. Review the copied documents and update `../SKILL.md` if its summary no longer
   matches the handbook. Surface material policy changes for human review.
5. Commit the refreshed snapshots, this source record, and any skill updates
   together in Vanessa.
